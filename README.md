# Wobblewild Testing Downloads

Wobblewild is an original Windows game about caring for your creature, exploring Tumblewick and making a home. Keyboard and screen-reader accessibility are central to development; mouse support is also available.

This repository hosts approved Testing downloads and update feeds. These are early prereleases, not production-ready releases. Game source and player saves are not stored here.

Download the ZIP from the named Testing release, extract everything, run **Wobblewild Setup.exe**, choose **Install Wobblewild**, then **Launch Wobblewild**. Do not use GitHub's automatically generated source archives to install the game.

Future updates: Main Menu → Check for Updates → Check Now. Close the game normally before installing an update. Saves and settings stay separate from application updates.

Executables are unsigned; Windows may display an unknown-publisher or SmartScreen warning. Live NVDA and clean-PC acceptance remain in progress. Four inherited audio provenance warnings remain unresolved; this is friend Testing, not a Stable launch or complete asset-clearance claim.
